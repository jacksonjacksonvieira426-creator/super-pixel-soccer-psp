# Super Pixel Soccer PSP
Jogo de futebol 2D de fas, nao oficial.

- `lua/`  versao Lua Player (jogavel agora)
- `src/`  versao C com PSPSDK + SDL2 (em construcao)
- `.github/workflows/build.yml`  compila o EBOOT.PBP no GitHub Actions

Baixe o resultado em Actions > ultimo build > Artifacts > SuperPixelSoccer-PSP.
Copie a pasta SuperPixelSoccer para ms0:/PSP/GAME/ ou abra o EBOOT.PBP no PPSSPP.
